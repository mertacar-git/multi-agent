# Multi-Agent AI System

## Overview

A system where multiple AI agents collaborate to solve tasks.

## Agents

* Planner
* Developer
* Reviewer

## Tech Stack

* Python
* LangChain / CrewAI

## Features

* Task decomposition
* Role-based prompting
* Iterative improvement

## Optimization

* Single model reused across roles
* No heavy GPU usage

## Flow

User → Planner → Developer → Reviewer

## Goal

Simulate real-world AI collaboration
